Vibe Jam 2026 · Saab · 9–10 November

Build a game in two days

One that someone else can sit down and play, in the browser, at your team's address. Claude Code writes the code. You decide, instruct, check and steer.

The one ruleSomewhere, you have to include a button that you really should not press.

1Log in

  • claude.ai/code, log in with teamN@rawe.se. Adrian gives you the link (lives 10 min)
  • Accept the invite to VibeJam2026
  • Sign in with GitHub and pick vibe-jam-2026/team-N

2Publish

  • Claude pushes to its own branch. Ask it to open a pull request
  • Merge it on github.com. A minute later it is live at vibe-jam-2026.github.io/team-N
  • The game starts from index.html at the top, relative paths

3The clock

  • Day 1: running at 1:30, playable at 3:00
  • Build on between the days if you like
  • Day 2: 10-minute demo per team, live. Then everyone plays and votes
